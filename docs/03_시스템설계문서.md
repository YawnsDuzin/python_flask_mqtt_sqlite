# 시스템 설계 문서

## 1. 시스템 개요

### 1.1 목적
**지하 및 밀폐공간 환경 센서** 데이터를 MQTT 프로토콜로 수신하여
파싱, 저장하고 실시간 모니터링 및 알람 관리를 제공하는 웹 기반 시스템

### 1.2 주요 기능
- 다중 MQTT 토픽 구독 (`{site_code}/U`, `{site_code}/W/{sensor}`)
- 14종 환경/가스 센서 데이터 파싱
- SQLite 데이터베이스 저장 (현장/장치/센서 데이터)
- 4단계 알람 레벨 관리
- MQTT 포워딩 (다른 브로커로 전송(AWS))
- 웹 대시보드를 통한 실시간 모니터링

### 3.2 테이블 생성 SQL
```sql
-- sites 테이블 (현장)
CREATE TABLE IF NOT EXISTS sites (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    site_code VARCHAR(20) UNIQUE NOT NULL,
    h_cd VARCHAR(10) NOT NULL,
    s_cd VARCHAR(10) NOT NULL,
    name VARCHAR(100),
    description TEXT,
    is_active BOOLEAN DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- devices 테이블 (장치)
CREATE TABLE IF NOT EXISTS devices (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id VARCHAR(30) UNIQUE NOT NULL,
    site_code VARCHAR(20) NOT NULL,
    dv_no VARCHAR(10),
    name VARCHAR(100),
    description TEXT,
    is_active BOOLEAN DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (site_code) REFERENCES sites(site_code)
);

-- environment_data 테이블 (환경 데이터)
CREATE TABLE IF NOT EXISTS environment_data (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id VARCHAR(30) NOT NULL,
    site_code VARCHAR(20) NOT NULL,
    h_cd VARCHAR(10),
    s_cd VARCHAR(10),
    dv_no VARCHAR(10),
    o2 REAL, no2 REAL, co REAL, co2 REAL,
    h2s REAL, ch4 REAL, ch2o REAL, o3 REAL,
    pm25 REAL, pm10 REAL, pm1 REAL,
    temp REAL, humi REAL, voc REAL,
    check_time DATETIME,
    topic VARCHAR(200),
    qos INTEGER DEFAULT 0,
    raw_payload TEXT,
    received_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (device_id) REFERENCES devices(device_id),
    FOREIGN KEY (site_code) REFERENCES sites(site_code)
);

-- 인덱스 생성
CREATE INDEX IF NOT EXISTS idx_env_data_device_id ON environment_data(device_id);
CREATE INDEX IF NOT EXISTS idx_env_data_site_code ON environment_data(site_code);
CREATE INDEX IF NOT EXISTS idx_env_data_check_time ON environment_data(check_time);
CREATE INDEX IF NOT EXISTS idx_env_data_received_at ON environment_data(received_at);

-- alarm_log 테이블 (알람 로그)
CREATE TABLE IF NOT EXISTS alarm_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id VARCHAR(30),
    site_code VARCHAR(20),
    dv_no VARCHAR(10),
    sensor_type VARCHAR(20) NOT NULL,
    value REAL,
    level INTEGER DEFAULT 0,
    alarm_time DATETIME,
    topic VARCHAR(200),
    raw_payload TEXT,
    acknowledged BOOLEAN DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (device_id) REFERENCES devices(device_id)
);

-- mqtt_logs 테이블
CREATE TABLE IF NOT EXISTS mqtt_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    event_type VARCHAR(20) NOT NULL,
    topic VARCHAR(200),
    message TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 7. MQTT 토픽 구조

### 7.1 수신 토픽 (Subscribe)
```
{site_code}/U             # 환경 데이터
{site_code}/W/{sensor}    # 알람 데이터

예시:
H001S0001/U               # H001S0001 현장 환경 데이터
H001S0001/W/O2            # 산소 알람
H001S0001/W/CO            # 일산화탄소 알람
H001S0001/W/H2S           # 황화수소 알람

구독 패턴:
+/U                       # 모든 현장 환경 데이터
+/W/+                     # 모든 현장 알람 데이터
```

### 7.2 포워딩 토픽 (Publish - 포워딩 활성화 시)
```
{prefix}/{original_topic}

예시:
forwarded/H001S0001/U           # 환경 데이터 포워딩
forwarded/H001S0001/W/O2        # 알람 데이터 포워딩
```

### 7.3 환경 데이터 메시지 형식
```json
{
  "hCd": "H001",
  "sCd": "S0001",
  "dvNo": "1",
  "data1": "20.9",   // O2 (%)
  "data2": "0.1",    // NO2 (ppm)
  "data3": "5.0",    // CO (ppm)
  "data4": "450",    // CO2 (ppm)
  "data5": "0.5",    // H2S (ppm)
  "data6": "0.0",    // CH4 (%LEL)
  "data7": "0.02",   // CH2O (ppm)
  "data8": "0.03",   // O3 (ppm)
  "data9": "15",     // PM2.5 (μg/m³)
  "data10": "25",    // PM10 (μg/m³)
  "data11": "25.5",  // 온도 (°C)
  "data12": "60",    // 습도 (%)
  "data13": "0.1",   // VOC (ppm)
  "data14": "10",    // PM1 (μg/m³)
  "checkTime": "2025-01-15 10:30:00"
}
```

### 7.4 알람 데이터 메시지 형식
```json
{
  "dvNo": "1",
  "value": "23.5",
  "level": "2",      // 0:정상, 1:주의, 2:경고, 3:위험
  "etc": "",
  "time": "2025-01-15 10:30:00"
}
```

## 8. 에러 처리 전략

### 8.1 MQTT 연결 오류
- 자동 재연결 (지수 백오프)
- 연결 상태 로깅
- 웹 대시보드에 연결 상태 표시

### 8.2 데이터 파싱 오류
- 오류 로깅 (원본 데이터 포함)
- 기본 파서로 폴백
- 파싱 실패 통계 수집

### 8.3 데이터베이스 오류
- 트랜잭션 롤백
- 재시도 로직
- 오류 알림
